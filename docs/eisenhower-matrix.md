# Eisenhower Matrix: Workout Tracker

## Q1: Urgent and Important (Do First, MVP 1)
- WorkoutEntry class (exercise, sets, reps, weight, date)
- CLI menu loop
- Log a new entry
- Save entries to a file
- Load entries on startup
- View all history

## Q2: Not Urgent but Important (Schedule, MVP 2 and 3)
- Input validation (no negative weights, bad numbers)
- Personal record per exercise
- Weekly total volume
- Filter history by exercise or date
- Edit and delete entries
- Basic unit tests
- Design doc and README

## Q3: Urgent but Not Important (Minimize)
- Polishing menu text and spacing
- Perfecting the file format
- Refactoring early code
- README screenshots

## Q4: Not Urgent and Not Important (Drop for Now)
- GUI (Swing or JavaFX)
- Charts and graphs
- Cloud sync or user accounts
- Workout templates or timers

## MVP Breakdown

**MVP 1: It works.** Log an entry, save it, restart the program, and see it again.

**MVP 2: It's useful.** Add validation, filtering, and personal records.

**MVP 3: It's solid.** Add weekly volume stats, edit and delete, and tests, then finish the documentation.

**Stretch goals:** Only start Q4 items after MVP 3 is complete.
